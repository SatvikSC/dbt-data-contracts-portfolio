## Local-only (add to `.gitignore` if not already)

| File / Directory | Reason |
|---|---|
| `profiles.yml` | Contains database credentials and file paths — machine-specific |
| `target/` | Compiled SQL, manifests, run results — regenerated by `dbt run` |
| `dbt_packages/` | Downloaded by `dbt deps` — equivalent of `node_modules` |
| `.env` | Secrets — **never commit**; `.env.example` is the safe template |
| `logs/` | dbt run logs — local only |
| `activate_env.ps1` | Machine-specific venv activation script |
